# 🍌 원숭이의 바나나 런 (Monkey Banana Run)

> **회사명:** Smile Games  
> **개발팀:** 최지훈, 박주아, 김이수, 최우영, 전준우  
> **서비스 형태:** GitHub Pages 기반 웹 브라우저 3D 러닝 & 연산 학습 게임

---

## 🎮 게임 소개
황금 바나나를 훔쳐 달아나는 장난꾸러기 원숭이의 스릴 넘치는 탈출 러닝 액션!
뒤쫓아오는 용(드래곤)을 피해 장애물을 넘고, 코인을 모으고, 중간중간 등장하는 3개의 문에 적힌 계산 문제를 풀어 올바른 문으로 돌진하세요!

## 🕹 조작 방법
- **왼쪽 이동:** `←` 또는 `A`
- **오른쪽 이동:** `→` 또는 `D`
- **점프:** `Space` 또는 `↑` / `W`
- **시점 회전 (쇼케이스 모드):** 마우스 좌클릭 드래그 & 휠 줌인/줌아웃
